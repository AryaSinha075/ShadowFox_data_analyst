## Project Title

Sales Analysis & Spreadsheet Dashboard

## Project Overview

This project focuses on analyzing a structured sales dataset using Microsoft Excel.

The objective was to clean and organize the dataset, calculate key business metrics, identify sales trends and performance differences, create visualizations, and develop a spreadsheet-based dashboard.

## Dataset

The dataset contains sales-related information including:

- Product ID
- Sale Date
- Sales Representative
- Region
- Sales Amount
- Quantity Sold
- Product Category
- Unit Cost
- Unit Price
- Customer Type
- Discount
- Payment Method
- Sales Channel

## Data Preparation

The project includes:

- Data organization
- Missing-value checks
- Duplicate checking
- Date validation
- Numerical value validation
- Separate raw and cleaned datasets

## Analysis Performed

The analysis includes:

- Key sales metrics
- Monthly sales trend
- Product category performance
- Regional sales performance
- Sales representative performance
- Top 10 products by sales
- Customer type analysis
- Sales channel analysis

## Dashboard

An Excel dashboard was created containing:

- Total Sales
- Total Quantity
- Average Sales
- Number of Transactions
- Monthly Sales Trend
- Category Performance
- Regional Performance
- Sales Representative Performance
- Top 10 Products
- Customer Type Analysis
- Sales Channel Analysis

## Key Findings

- Total sales were approximately ₹5.02 million.
- The dataset contains 1,000 transactions.
- North recorded the highest regional sales.
- Clothing was the highest-performing product category.
- David was the top-performing sales representative.
- January recorded the highest monthly sales.
- Returning and new customers contributed almost equally.
- Retail sales were slightly higher than online sales.
